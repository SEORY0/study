저항 하나와 커패시터 하나로 된 RC 회로는 에너지를 저장하는 소자가 하나뿐인 가장 단순한 동적 회로다. 스위치를 켠 직후처럼 정상상태로 가는 도중의 응답을 과도응답(transient response)이라 하는데, RC 회로에서는 그것이 지수함수 하나로 끝나고 시간의 눈금도 시정수(time constant) τ = RC 하나뿐이다. 디지털 회로의 출력 노드도 1차 근사로는 이 회로라서 게이트의 속도와 전력이 여기서 정해진다.

## 미분방정식 하나

```ascii
         R      i →
  ┌────/\/\/───────────┬─────○ +
 ┌┴┐                  ─┴─
 │+│ V·u(t)         C ─┬─   v_C(t)
 │-│                   │
 └┬┘                   │
  └────────────────────┴─────○ −
```

그림. 계단 전원 V·u(t)가 R을 거쳐 C를 충전한다

위쪽 노드에서 KCL을 쓰면 R을 지나는 전류 (v<sub>s</sub> − v<sub>C</sub>)/R이 C로 들어가는 전류 C·dv<sub>C</sub>/dt와 같다. 처음에 비어 있던 커패시터에 계단 V·u(t)를 넣으면 계단응답(step response)은 지수함수다.

```eq
      dv_C
RC · ────── + v_C = v_s(t)
       dt

v_C(t) = V·(1 − e^(−t/τ)),   i(t) = (V/R)·e^(−t/τ)
```

식을 dv<sub>C</sub>/dt = (V − v<sub>C</sub>)/τ로 고쳐 읽으면 직관이 생긴다. 충전 속도는 남은 거리 V − v<sub>C</sub>에 비례하고, 그래서 τ가 지날 때마다 남은 거리가 e<sup>−1</sup> ≈ 0.368배로 줄어든다. 처음 기울기 V/τ를 그대로 유지했다면 정확히 t = τ에 V에 닿았을 것이다.

R = 1 kΩ, C = 1 μF이면 τ = 1 ms다. 5 V 계단을 넣으면 첫 순간의 전류는 V/R = 5 mA이고, 1 ms 뒤에 3.16 V, 5 ms 뒤에 4.97 V가 된다.

## 임펄스 응답과 컨볼루션

입력이 임펄스 δ(t)면 커패시터는 한순간에 1/RC까지 충전된 뒤 R을 통해 지수적으로 방전한다. 이것이 RC 회로의 임펄스 응답(impulse response)이다.

```eq
         1
h(t) = ──── · e^(−t/τ) · u(t)
        RC
```

계단은 임펄스를 시간에 대해 쌓은 것이니 계단응답도 h(t)를 쌓은 것, 곧 ∫<sub>0</sub><sup>t</sup> h(λ)dλ = 1 − e<sup>−t/τ</sup>다. 적분 변수를 λ로 쓴 것은 시정수 τ와 겹치지 않게 하려는 것이다. 입력이 무엇이든 응답은 입력과 h(t)의 컨볼루션(convolution)이다.

```eq
          ∞
v_C(t) =  ∫  v_s(λ)·h(t − λ) dλ  =  (v_s * h)(t)
         −∞
```

h(t − λ)는 (t − λ)초 전의 입력에 주는 가중치이고, 그 가중치가 e<sup>−(t−λ)/τ</sup>로 줄어든다. 즉 RC 회로는 과거의 입력을 최근 것일수록 크게 섞는 가중 평균기이고, 기억의 길이가 대략 τ다. 같은 RC를 주파수로 보면 차단 주파수가 ω<sub>c</sub> = 1/RC인 저역통과 필터인데, 그 계산은 [임피던스](/study/impedance/)에 있다.

## 에너지의 절반

0 V에서 V까지 충전하는 동안 전원은 전하 Q = C·V를 일정한 전압 V로 밀어 넣으므로 C·V<sup>2</sup>를 내놓는다. 커패시터에 남는 것은 ½·C·V<sup>2</sup>뿐이고, 나머지 절반은 R에서 열이 된다.

```eq
       ∞
E_R =  ∫ i(t)²·R dt  =  (V²/R)·(τ/2)  =  C·V²/2
       0
```

결과에 R이 없다. R을 줄이면 전류는 커지지만 그만큼 빨리 끝나서 손실은 그대로다. 위 예제(1 μF, 5 V)라면 전원이 25 μJ을 내놓고, 12.5 μJ이 저장되고, 12.5 μJ이 열이 된다. 손실을 줄이려면 R이 아니라 전원 쪽을 바꿔서, 전압을 τ보다 훨씬 천천히 올려야 한다.

```ascii
 supply  C·V²     ████████████████████  25 μJ
 C       C·V²/2   ██████████            12.5 μJ  stored
 R       C·V²/2             ██████████  12.5 μJ  heat
```

그림. 계단으로 충전하면 전원이 내놓은 에너지는 R과 무관하게 반씩 나뉜다

## 이어지는 곳

컨볼루션 줄에서 앞 역은 [컨볼루션](/study/convolution/)이다. 거기서 y = x∗h는 입력을 임펄스로 쪼개고, 각 임펄스가 만든 h를 밀어서 더한 것이었다. RC 회로에서는 그 h가 추상적인 함수가 아니라 R과 C가 정한 (1/RC)·e<sup>−t/RC</sup>u(t)다. 계단응답이 h의 적분이라는 것도 같은 그림이다. 이 식이 나온 미분방정식 자체는 [선형 미분방정식](/study/ode/)의 1차 예제와 같다.

다음 역은 [CNN의 합성곱](/study/cnn/)이다. 시간 간격 T로 샘플링한 세계에서 같은 모양의 커널은 a<sup>n</sup>(a = e<sup>−T/τ</sup>)이고, y[n] = a·y[n−1] + (1−a)·x[n]은 커널이 (1−a)·a<sup>n</sup>인 지수 이동평균이다. 과거 입력에 정해진 가중치를 곱해 더한다는 점에서 CNN의 합성곱과 같은 연산이다. 차이는 가중치를 누가 정하느냐다. RC에서는 물리, 곧 R과 C가 커널을 정하고 CNN에서는 학습이 정한다. 또 RC의 커널은 과거만 보는 인과(causal) 커널이지만, 이미지 커널은 위아래 양옆을 다 본다.

스위칭 전력 줄은 여기서 출발한다. 다음 역 [CMOS 인버터](/study/cmos/)의 출력 노드는 부하 커패시턴스 C<sub>L</sub>을 PMOS의 온 저항으로 채우고 NMOS의 온 저항으로 비우는 RC 회로다. 위의 에너지 계산이 그대로 넘어간다. 출력이 0에서 1로 오를 때마다 전원이 C·V<sup>2</sup>를 내놓아 절반은 PMOS에서 열이 되고, 1에서 0으로 내릴 때 저장된 나머지 절반이 NMOS에서 열이 된다. 그래서 한 번 오르내리는 데 C·V<sup>2</sup>이고, 초당 α·f번이면 P = α·C·V<sup>2</sup>·f다. 지연 0.69·R<sub>on</sub>·C<sub>L</sub>의 0.69도 여기서 나온다. 1 − e<sup>−t/τ</sup> = 0.5를 풀면 t = τ·ln 2 ≈ 0.69τ다.
