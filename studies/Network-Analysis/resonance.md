직렬 RLC 회로는 에너지를 인덕터의 자기장과 커패시터의 전기장 사이에서 주고받는 2차 시스템이다. 정현파로 보면 두 리액턴스가 서로 상쇄되는 공진 주파수(resonant frequency) ω<sub>0</sub>에서 임피던스가 R까지 떨어지고, 과도응답으로 보면 특성방정식의 두 근, 곧 극점(pole)이 놓인 자리가 회로가 울릴지 말지를 정한다. 두 그림은 같은 사실을 양쪽에서 본 것이고, 둘을 잇는 식이 하나 있다.

## 임피던스로 보면

```eq
Z(jω) = R + jωL + 1/(jωC) = R + j(ωL − 1/(ωC))

        1             ω₀L           ω₀     R
ω₀ = ───────     Q = ─────     B = ──── = ───
      √(LC)            R             Q     L
```

ω < ω<sub>0</sub>에서는 커패시터의 리액턴스가 이겨서 용량성, ω > ω<sub>0</sub>에서는 유도성이다. ω<sub>0</sub>에서 허수부가 0이 되어 Z = R이고, 전류는 최대 V/R이 되며 전압과 위상이 같다. L과 C의 전압이 사라진 것은 아니다. 서로 반대 위상이라 상쇄될 뿐이고, 각각의 크기는 |V<sub>L</sub>| = |V<sub>C</sub>| = Q·|V|로 전원의 Q배다. 품질 계수(quality factor) Q가 클수록 봉우리가 좁고, 반전력 대역폭(bandwidth), 곧 |I|가 최댓값의 1/√2 이상인 폭이 B = ω<sub>0</sub>/Q다.

L = 10 mH, C = 1 μF, R = 10 Ω이면 ω<sub>0</sub> = 10<sup>4</sup> rad/s(f<sub>0</sub> ≈ 1.59 kHz), Q = 10, B = 1000 rad/s다. 진폭 1 V 전원을 걸면 공진에서 전류가 100 mA, 커패시터 전압이 10 V다. 반전력 점은 9512.5 rad/s와 10512.5 rad/s이고, 차이가 정확히 1000, 곱이 정확히 ω<sub>0</sub><sup>2</sup>이다.

그림. 전류 크기를 각자의 최댓값으로 나눈 공진 곡선. L, C는 그대로 두고 R만 10 Ω(Q = 10)과 50 Ω(Q = 2)으로 바꿨다

## 극점으로 보면

시간 영역에서 KVL을 쓰고 한 번 미분하면 2차 미분방정식이 되고, e<sup>st</sup>를 넣으면 특성방정식(characteristic equation)이 나온다. 표준형 s<sup>2</sup> + 2ζω<sub>n</sub>s + ω<sub>n</sub><sup>2</sup>과 비교하면 ω<sub>n</sub>이 곧 ω<sub>0</sub>이고, 감쇠비(damping ratio) ζ가 Q와 묶인다.

```eq
s² + (R/L)·s + 1/(LC) = 0

ζ = (R/2)·√(C/L) = 1/(2Q)

s = −α ± jω_d,   α = R/(2L),   ω_d = √(ω₀² − α²)
```

- ζ < 1, 부족감쇠(underdamped): 켤레 복소 극점. e<sup>−αt</sup>로 줄어드는 진동
- ζ = 1, 임계감쇠(critically damped): R = 2√(L/C)에서 −ω<sub>0</sub>에 중근. 넘치지 않는 응답 중 가장 빨리 자리 잡는다
- ζ > 1, 과감쇠(overdamped): 음의 실근 두 개. 원점에 가까운 근이 느린 꼬리를 남겨 느리게 기어간다

예제는 ζ = 0.05, 극점은 −500 ± j9987.5다. 진동은 시정수 1/α = 2 ms로 줄어드는데 한 주기가 2π/ω<sub>d</sub> ≈ 0.63 ms라서, e<sup>−1</sup>로 줄 때까지 약 Q/π ≈ 3.2번 울린다. 임계감쇠가 되는 R은 2√(L/C) = 200 Ω이다.

```ascii
                jω
                 ▲
            ╭─◀──× +jω₀   R = 0
         ╭──╯    │
       ╭─╯       │
      ╭╯ |s|=ω₀  │
      │          │
 ───◀─●─▶────────┼───▶ σ
 −ω₀  │          │
      ╰╮         │
       ╰─╮       │
         ╰──╮    │
            ╰─◀──× −jω₀   R = 0
```

그림. L, C를 고정하고 R을 0에서 키울 때 극점의 길. ±jω<sub>0</sub>에서 출발해 반지름 ω<sub>0</sub>인 원을 따라 왼쪽으로 돌아 R = 200 Ω(ζ = 1)에서 −ω<sub>0</sub>에 만나고, 그 뒤로는 실수축 위에서 양쪽으로 갈라진다

원 위에 있는 동안 |s|<sup>2</sup> = α<sup>2</sup> + ω<sub>d</sub><sup>2</sup> = ω<sub>0</sub><sup>2</sup>이라서 원점에서 극점까지의 거리는 늘 ω<sub>0</sub>이다. R이 바꾸는 것은 원 위의 각도, 곧 ζ뿐이다.

## 두 그림을 잇는 식

B = R/L이고 α = R/(2L)이니 B = 2α다. 공진 봉우리의 반전력 폭은 극점이 jω축에서 떨어진 거리의 정확히 두 배다. 기하로 보면 이유가 보인다. 전류의 전달함수 I/V = (s/L)/((s − p<sub>1</sub>)(s − p<sub>2</sub>))에서 |I|는 jω에서 두 극점까지 거리의 곱에 반비례한다. Q가 크면 봉우리 근처에서 먼 극점까지의 거리(≈ 2ω<sub>0</sub>)와 |jω|(≈ ω<sub>0</sub>)는 거의 그대로이고, 가까운 극점까지의 거리만 크게 변한다.

```ascii
                jω
                 ▲
                 ●  ≈ ω₀ + α    −3 dB
         √2·α  / │
             /   │
 −α + jω_d ×──α──●  ω_d ≈ ω₀    peak
             \   │
               \ │
                 ●  ≈ ω₀ − α    −3 dB
                 │
```

그림. 위쪽 극점 근처를 확대한 것(아래 극점은 2ω<sub>d</sub> 아래에 있다). jω가 극점 옆을 지날 때 거리가 α로 가장 짧고, 위아래로 α만큼 벗어나면 √2·α가 되어 |I|가 1/√2로 떨어진다

예제 값을 넣으면 α = 500이니 B = 1000 rad/s로 위의 계산과 같다. 극점이 jω축에 가까울수록, 곧 R이 작을수록 봉우리는 좁고 높아지고, R = 0이면 극점이 축 위에 올라가 그 주파수에서 응답이 무한대가 된다.

## 이어지는 곳

극점 줄에서 앞 역은 [라플라스 변환과 전달함수](/study/laplace/)다. 거기서 H(s)의 분모가 0이 되는 s가 극점이고, 모든 극점이 왼쪽 반평면에 있어야 안정하다고 했다. 여기서는 그 분모가 실제 부품 값으로 채워진다: s<sup>2</sup> + (R/L)s + 1/(LC). 극점의 실수부 −α = −R/(2L)이 진동이 줄어드는 속도이고, 허수부 ω<sub>d</sub>가 울리는 주파수다. R = 0이면 극점이 jω축 위에 올라가 영원히 울리고, 저항은 극점을 왼쪽으로 끌어당겨 회로를 안정하게 만든다. 같은 꼴의 방정식과 근의 분류는 [선형 미분방정식](/study/ode/)에서 먼저 나왔다.

다음 역은 [보드 선도](/study/bode/)다. 커패시터 전압을 출력으로 잡으면 H(s) = V<sub>C</sub>/V<sub>s</sub> = 1/(LCs<sup>2</sup> + RCs + 1)이고, 이 복소 극점 쌍은 보드 선도에서 ω<sub>0</sub> 근처의 봉우리와 그 위의 −40 dB/decade 기울기로 나타난다. 실수 극점 하나가 −20 dB/decade였으니 극점이 둘이라 두 배다. 봉우리의 높이는 ω<sub>0</sub>에서 Q배(예제에서 20 dB)이고, 위의 기하 그대로 극점이 jω축에 가까울수록 높다. 부귀환 증폭기의 폐루프 응답에 이런 봉우리가 생기면 위상 여유가 작다는 신호이기도 하다.
