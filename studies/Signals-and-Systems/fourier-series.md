푸리에 급수(Fourier series)는 주기 T인 신호를 기본 각주파수 ω₀ = 2π/T의 정수배로 도는 복소지수들의 합으로 쓰는 방법이다. 시간축에서는 복잡한 파형도 계수 a<sub>k</sub>의 목록으로 보면 몇 개의 숫자다. 복소지수는 LTI 시스템의 고유함수라서, 이렇게 쪼개 두면 시스템 통과가 성분마다 숫자 하나 곱하기가 된다.

## 합성식과 분석식

```eq
          ∞
x(t)  =   ∑   a_k · e^(jkω₀t)          ω₀ = 2π/T
        k=−∞

          1   T
a_k   =   ─   ∫  x(t) · e^(−jkω₀t) dt
          T   0
```

분석식이 성립하는 이유는 직교성(orthogonality)이다. 서로 다른 정수 k, m에 대해 e<sup>jkω₀t</sup>·e<sup>−jmω₀t</sup>를 한 주기 적분하면, 복소평면에서 정확히 (k − m)바퀴를 돌고 제자리로 오므로 0이다. k = m일 때만 T가 남는다. 그래서 x(t)에 e<sup>−jkω₀t</sup>를 곱해 한 주기 적분하면 다른 성분은 다 사라지고 a<sub>k</sub>만 걸러진다. x(t)가 실수이면 a<sub>−k</sub>는 a<sub>k</sub>의 켤레복소수이고, 둘을 묶으면 진폭 2|a<sub>k</sub>|, 위상 ∠a<sub>k</sub>인 실수 cos 하나가 된다.

## 구형파

반주기는 +1, 반주기는 −1인 구형파(square wave, 0 < t < T/2에서 +1)를 분석식에 넣으면 직류와 짝수 고조파(harmonic)는 0이고, 홀수 k에서만 a<sub>k</sub> = 2/(jπk)가 나온다. 실수 꼴로 쓰면 다음과 같다.

```eq
          4                  1
x(t)  =   ─  ·      ∑        ─ · sin(kω₀t)
          π    k = 1,3,5,…   k
```

진폭 2|a<sub>k</sub>| = 4/(πk)는 1.273, 0.424, 0.255, 0.182, …로 정확히 1/k를 따라 준다.

```ascii
       ▲ 2|a_k| = 4/(πk)
 1.27  ┤  ██
       │  ██
       │  ██
       │  ██
       │  ██
 0.42  ┤  ██    ▅▅
       │  ██    ██    ▅▅    ▁▁
       │  ██    ██    ██    ██    ▇▇    ▆▆    ▅▅
       └──────────────────────────────────────────▶ k
          1     3     5     7     9     11    13
```

그림. 구형파의 선 스펙트럼. 홀수 고조파만 있고 높이는 1/k로 준다

전력으로 보면 더 분명하다. 파스발 정리(Parseval's theorem)에 따라 시간에서 잰 평균 전력은 계수의 제곱합 ∑|a<sub>k</sub>|<sup>2</sup>과 같다. 구형파의 평균 전력은 1이고(값의 제곱이 늘 1), 진폭 A인 정현파 하나는 a<sub>k</sub>와 a<sub>−k</sub> 한 쌍이라 2·(A/2)<sup>2</sup> = A<sup>2</sup>/2를 갖는다. 기본파 하나가 (4/π)<sup>2</sup>/2 = 8/π<sup>2</sup> ≈ 0.811, 즉 전력의 81 %를 갖고, 3차가 9.0 %, 5차가 3.2 %를 보태 5차까지 93 %다. 남은 7 %가 모서리의 날카로움을 만든다.

항을 유한하게 자르면 불연속점 근처에 뿔이 솟는다. 기본파 하나뿐이면 꼭대기가 1.273이고, 9차까지 더하면 1.182다. 항을 계속 늘려도 꼭대기는 1로 내려오지 않고 약 1.179에서 멈춘다. 뿔은 점프 쪽으로 좁아질 뿐 높이는 점프 크기 2의 약 9 %로 남는데, 이것이 깁스 현상(Gibbs phenomenon)이다. 불연속점 바로 위(t = 0)에서는 항을 몇 개 쓰든 sin(kω₀t)가 모두 0이라 급수 값이 0, 즉 −1과 +1의 한가운데다. 급수는 점프를 반으로 갈라 수렴한다.

계수가 줄어드는 속도는 파형이 얼마나 매끄러운지를 그대로 말해 준다. 구형파를 적분하면 같은 주기의 삼각파(triangle wave)가 되는데, 적분은 k차 성분을 jkω₀로 나누므로 진폭이 1/k에서 1/k<sup>2</sup>로 바뀐다. 꼭짓값 1인 삼각파의 진폭은 8/(π<sup>2</sup>k<sup>2</sup>), 즉 0.811, 0.090, 0.032로 구형파보다 훨씬 빨리 사라진다. 점프가 있으면 1/k, 꺾임만 있으면 1/k<sup>2</sup>, 더 매끄러우면 더 빨리 준다. 날카로운 신호일수록 넓은 대역을 차지한다는 말과 같다.

## 고조파마다 따로 지나간다

구형파를 RC 저역통과 필터 H(jω) = 1/(1 + jωRC)에 넣고 코너를 기본파에 맞춘다(ω₀RC = 1). 각 고조파는 고유함수 e<sup>±jkω₀t</sup>의 쌍이므로 서로 섞이지 않고, k차는 |H(jkω₀)| = 1/√(1 + k<sup>2</sup>)배가 되어 나온다.

```ascii
  k    in = 4/(πk)    |H(jkω₀)|    out
 ───   ───────────    ─────────    ─────
  1       1.273         0.707      0.900
  3       0.424         0.316      0.134
  5       0.255         0.196      0.050
  7       0.182         0.141      0.026
```

그림. 출력 진폭 = 입력 진폭 × |H|, 고조파마다 곱셈 한 번

3차 고조파의 상대 크기가 1/3 = 0.333에서 0.134/0.900 = 0.149로 줄어 출력은 사인에 가까워진다. 위상도 고조파마다 −45°, −71.6°, −78.7°로 다르게 밀린다. 이 계산 어디에도 미분방정식은 없다.

## 이어지는 곳

주파수 영역 줄(freq)은 여기서 시작한다. 다음 역은 [푸리에 변환](/study/fourier-transform/)이다. 주기 T를 늘리면 선 사이 간격 ω₀ = 2π/T가 좁아지고, T → ∞이면 선들이 붙어 연속 곡선이 된다. 식으로는 T·a<sub>k</sub> = ∫x(t)·e<sup>−jkω₀t</sup>dt(한 주기 적분)에서 kω₀를 연속 변수 ω로 바꾼 것이 X(jω)다. 거꾸로 읽으면 a<sub>k</sub>는 한 주기만 잘라 낸 신호의 푸리에 변환을 ω₀ 간격으로 찍어 T로 나눈 값이고, 위 막대 높이 2|a<sub>k</sub>|도 그 변환 곡선의 크기를 2/T배 해서 찍은 점이다. 시간에서 주기적이면 주파수에서 이산적이다.

고조파가 섞이지 않고 따로 지나가는 근거는 [복소지수와 고유함수](/study/eigenfunction/)의 y = H(s)·e<sup>st</sup>이고, sin을 복소지수 두 개로 바꾸는 것은 [오일러 공식](/study/euler/)이다. 위의 직교성 논리는 [OFDM](/study/ofdm/)에서 그대로 쓰인다. 부반송파를 Δf = 1/T 간격으로 놓으면 심볼 길이 T 동안 서로 정수 바퀴만큼 차이 나게 돌아서, 한 주기 적분(수신기의 FFT)이 각 부반송파를 따로 걸러 낸다.
