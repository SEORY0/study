상수계수 선형 미분방정식(linear ODE with constant coefficients)은 R, L, C로 만든 회로에 KCL과 KVL을 쓰면 나오는 방정식이다. 풀이의 핵심은 추측 하나다: y = e<sup>st</sup>를 넣으면 미분이 s 곱셈이 되어 미분방정식이 s에 대한 다항식으로 바뀐다. 그 다항식의 근이 놓인 자리만 보면 응답이 줄어들지, 진동할지, 터질지가 보인다.

## 특성방정식

2차까지만 쓰면 이런 꼴이다.

```eq
a₂·y'' + a₁·y' + a₀·y = x(t)
```

계수가 상수이고 y와 그 도함수가 1차로만 나온다. 선형이라서 해가 두 조각의 합으로 갈린다. 입력 x(t)를 따라가는 강제응답(forced response)과, 우변을 0으로 둔 방정식을 만족하는 자연응답(natural response)이다. 자연응답에 어떤 지수가 나올지는 입력이 아니라 회로가 정하고, 각 항의 크기는 초기조건이 정한다.

x = 0으로 두고 y = e<sup>st</sup>를 넣으면, 미분할 때마다 s가 하나씩 앞으로 나온다.

```eq
y = e^(st)  ⇒  y' = s·e^(st),  y'' = s²·e^(st)

(a₂s² + a₁s + a₀)·e^(st) = 0
⇒  a₂s² + a₁s + a₀ = 0
```

e<sup>st</sup>는 0이 될 수 없으니 괄호가 0이어야 한다. 이것이 특성방정식(characteristic equation)이다. 근 s₁, s₂마다 e<sup>s₁t</sup>, e<sup>s₂t</sup>가 해가 되고, 두 근이 다르면 자연응답은 그 선형결합 c₁e<sup>s₁t</sup> + c₂e<sup>s₂t</sup>이며 계수 c는 초기조건이 정한다. 미분방정식을 푸는 일이 다항식의 근을 찾는 일로 바뀌었다.

근의 자리가 곧 응답의 모양이다. s = σ + jω로 쓰면 실수부 σ는 e<sup>σt</sup>, 즉 줄어들거나 커지는 빠르기이고, 허수부 ω는 진동의 각주파수다. 실수 계수 방정식의 복소근은 항상 켤레 쌍으로 나오고, 두 항이 [오일러 공식](/study/euler/)으로 합쳐져 실수 신호 e<sup>σt</sup>·cos(ωt + φ)가 된다.

```ascii
                    ▲ jω
                    │
   × █▅▃▃▅▆▅▄▄▅▅    × █▆▂▂▆█▆▂▂▆█    × ▅▅▄▄▅▆▅▃▃▅█
                    │
     █▆▅▄▄▃▃▂▂▂▂    │ ▅▅▅▅▅▅▅▅▅▅▅      ▂▂▂▂▃▃▄▄▅▆█
 ──×────────────────×────────────────×─────────────▶ σ
                    │
                    │
   ×                ×                ×

 σ<0: dies out    σ=0: persists    σ>0: blows up
```

그림. s 평면 위 근(×)의 자리와 그 근이 만드는 자연응답. 막대 줄은 왼쪽에서 오른쪽으로 흐르는 시간 응답이고, 진동하는 줄은 가운데 높이가 0이다. 실수축 위의 근은 진동 없는 지수, 켤레 쌍은 진동이며, 같은 높이의 근은 같은 ω로 진동한다. 아래쪽 ×는 위쪽 근의 켤레다

## 1차: RC 방전

V₀로 충전된 커패시터 C를 저항 R로 방전시킨다. 두 소자가 만나는 노드에서 KCL을 쓰면 다음과 같다.

```eq
C·dv/dt + v/R = 0

RC·s + 1 = 0    ⇒    s = −1/RC = −1/τ

v(t) = V₀·e^(−t/τ)
```

근은 음의 실수 하나이고, 그 크기의 역수가 시정수(time constant) τ = RC다. R = 10 kΩ, C = 1 μF이면 τ = 10 ms, 근은 s = −100 s<sup>−1</sup>이다. V₀ = 5 V에서 시작하면 t = τ = 10 ms에서 5·e<sup>−1</sup> = 1.84 V, t = 5τ = 50 ms에서 5·e<sup>−5</sup> = 0.034 V(처음의 0.7 %)가 남는다. 근이 원점에서 멀수록, 즉 τ가 작을수록 빨리 사라진다.

## 2차: ζ가 근을 옮긴다

2차는 a₂로 나눈 뒤 a₀/a₂ = ω<sub>n</sub>², a₁/a₂ = 2ζω<sub>n</sub>으로 이름을 붙인 표준형으로 쓴다. ω<sub>n</sub>은 비감쇠 고유각주파수(undamped natural frequency), ζ는 감쇠비(damping ratio)다.

```eq
s² + 2ζω_n·s + ω_n² = 0

s = −ζω_n ± ω_n·√(ζ² − 1)
```

- ζ > 1, 과감쇠(overdamped): 서로 다른 음의 실근 두 개. 진동 없이 지수 두 개의 합이다.
- ζ = 1, 임계감쇠(critically damped): 중근 −ω<sub>n</sub>. 응답은 (c₁ + c₂t)·e<sup>−ω<sub>n</sub>t</sup>.
- 0 < ζ < 1, 부족감쇠(underdamped): 켤레근 −ζω<sub>n</sub> ± jω<sub>d</sub>, ω<sub>d</sub> = ω<sub>n</sub>√(1 − ζ²). 포락선(envelope) e<sup>−ζω<sub>n</sub>t</sup> 안에서 ω<sub>d</sub>로 진동한다.
- ζ = 0, 비감쇠(undamped): 근이 ±jω<sub>n</sub>으로 허수축 위에 있다. 진동이 영원히 이어진다.

부족감쇠일 때 원점에서 근까지의 거리는 √((ζω<sub>n</sub>)² + ω<sub>n</sub>²(1 − ζ²)) = ω<sub>n</sub>이므로 켤레근은 반지름 ω<sub>n</sub>인 원 위에 있고, 음의 실수축에서 잰 근의 각 θ는 cos θ = ζ를 만족한다. ζ를 0에서 키우면 근은 허수축에서 출발해 이 원을 따라 미끄러져 ζ = 1일 때 −ω<sub>n</sub>에서 만나고, 그 뒤로는 실수축 위에서 양쪽으로 갈라진다. 두 근의 곱은 언제나 ω<sub>n</sub>²이라서 한 근이 −∞ 쪽으로 가면 다른 근은 원점 쪽으로 다가온다. ω<sub>n</sub> = 1000 rad/s로 계산하면 다음과 같다.

```ascii
 ω_n = 1000 rad/s

 ζ     roots s           slow τ     overshoot
 ────  ────────────────  ─────────  ─────────
 0     ±j1000            ∞          100 %     비감쇠
 0.2   −200 ± j980       5.0 ms     52.7 %    부족감쇠
 0.7   −700 ± j714       1.43 ms    4.6 %     부족감쇠
 1     −1000 (double)    1.0 ms     0 %       임계감쇠
 2     −268, −3732       3.73 ms    0 %       과감쇠
```

그림. ζ에 따른 근, 가장 느린 지수 항의 시정수 −1/σ, 계단응답의 넘침(overshoot)

넘침은 계단 입력을 넣었을 때 최종값을 넘어서는 비율이다. 영점이 없는 표준 2차계 H(s) = ω<sub>n</sub>²/(s² + 2ζω<sub>n</sub>s + ω<sub>n</sub>²)에서는 부족감쇠일 때 e<sup>−πζ/√(1−ζ²)</sup>이다. 가장 느린 항의 시정수가 가장 짧은 것은 ζ = 1(1.0 ms)이고, 넘침을 4.6 % 허용하는 ζ = 0.7(1.43 ms)도 크게 뒤지지 않는다. 최종값의 ±2 % 안에 들어오는 시간으로 재도 ζ = 1이 5.8 ms, ζ = 0.7이 6.0 ms로 거의 같다. 감쇠를 더 키운 ζ = 2는 오히려 느리다(시정수 3.73 ms, ±2 %까지 14.9 ms). 원점 쪽으로 다가온 근 −268 하나가 전체 속도를 정하기 때문이다. 감쇠가 크다고 빨리 조용해지는 것이 아니다.

## 이어지는 곳

이 노트는 극점 줄의 출발점이고, 다음 정거장은 [라플라스 변환](/study/laplace/)이다. 거기서는 미분이 s 곱셈이 되는 일이 e<sup>st</sup> 추측 없이 변환의 규칙(d/dt → s)으로 일어난다. 초기조건을 0으로 두면 a₂y″ + a₁y′ + a₀y = x는 (a₂s² + a₁s + a₀)·Y(s) = X(s)가 되고, 전달함수(transfer function) H(s) = 1/(a₂s² + a₁s + a₀)의 분모가 여기의 특성다항식 그대로다. 그래서 특성근이 곧 H(s)의 극점(pole)이고, "모든 극점이 왼쪽 반평면에 있다"는 안정성 조건은 위 s 평면 그림의 왼쪽 열, 즉 모든 자연응답 항이 줄어든다는 말과 같다.

같은 방정식이 회로에서 다시 나온다.

- [RC 회로의 과도응답](/study/rc-transient/): 위 RC 회로를 0 V에서 계단 전원 V로 충전하면 방정식은 C·dv/dt + (v − V)/R = 0이 되고, 강제응답 V와 자연응답 −V·e<sup>−t/τ</sup>가 더해져 v(t) = V(1 − e<sup>−t/τ</sup>)가 된다. 근은 그대로 −1/τ이고, t = τ에서 63.2 %(= 1 − e<sup>−1</sup>)라는 숫자도 이 근에서 나온다.
- [RLC 공진](/study/resonance/): 직렬 RLC의 특성방정식 s² + (R/L)s + 1/(LC) = 0을 표준형과 맞대면 ω<sub>n</sub> = 1/√(LC), ζ = (R/2)√(C/L)이고, 품질계수(quality factor)는 Q = 1/(2ζ)다. 표의 ζ = 0.2는 Q = 2.5인 회로다. 그 노트에는 R을 키울 때 근이 위의 원을 따라 내려오는 그림이 있다.
- [보드 선도](/study/bode/): 극점 줄의 끝. 같은 RC를 저역통과 필터로 쓰면 H(s) = 1/(1 + sRC)의 극점이 바로 이 근 −1/τ이고, 주파수 응답에서 ω = 1/τ의 꺾임점(corner frequency, −3 dB, −45°)이 된다. 위 예제의 근 −100 s<sup>−1</sup>은 100 rad/s ≈ 15.9 Hz의 꺾임점으로 다시 나타난다. 2차 극점 쌍은 ω<sub>n</sub> 위에서 −40 dB/decade 기울기를 만들고, ζ < 1/√2 ≈ 0.707이면 그 앞에 공진 봉우리가 솟는다.
