선형 회로의 응답은 독립 전원 각각이 혼자 만든 응답의 합이다. 이것이 중첩의 원리(superposition)이고, 여기서 바로 테브난 등가(Thevenin equivalent)가 나온다. 저항과 전원이 아무리 얽혀 있어도 두 단자 밖에서 보면 전압원 V<sub>th</sub> 하나와 직렬 저항 R<sub>th</sub> 하나다. 부하를 바꿔 가며 계산할 때도, 증폭기의 입력 저항과 출력 저항을 말할 때도 결국 이 두 숫자로 돌아온다.

## 중첩의 원리

조건은 회로가 선형이라는 것 하나다. 저항, 선형 종속 전원, 초기 에너지가 없는 L과 C만 있으면 입력을 a배 하면 출력도 a배가 되고, 두 입력의 합에는 두 출력의 합이 나온다. 그래서 독립 전원을 하나만 남기고 나머지를 끈 회로를 전원 수만큼 풀어서 더하면 된다.

- 전압원을 끈다: V = 0, 즉 단락(short)
- 전류원을 끈다: I = 0, 즉 개방(open)
- 종속 전원은 끄지 않는다. 입력이 아니라 회로의 일부다
- 전력은 중첩되지 않는다. P = I<sup>2</sup>R은 I에 대해 선형이 아니다

```ascii
      R1 6kΩ      a           R3 1kΩ
  ┌───/\/\/───┬────────┬──────/\/\/───○ A
 ┌┴┐         ┌┴┐      ┌┴┐
 │+│ Vs      │ │ R2   │↑│ Is
 │-│ 12V     │ │ 3kΩ  │ │ 2mA
 └┬┘         └┬┘      └┬┘
  └───────────┴────────┴──────────────○ B
```

그림. 예제 회로. 노드 a에 12 V 전원(6 kΩ 경유), 3 kΩ, 2 mA 전류원이 물려 있고 1 kΩ을 거쳐 단자 A로 나간다

A, B를 열어 두면 R3에는 전류가 흐르지 않으므로 단자 전압은 노드 a의 전압이다. 전원을 하나씩 켜서 더한다. Vs만 켜면(Is 개방) 6 kΩ과 3 kΩ의 분압이고, Is만 켜면(Vs 단락) 2 mA가 6 kΩ∥3 kΩ = 2 kΩ에 흐른다.

```eq
              3k              6k·3k
V_oc = 12 V·───────  +  2 mA·───────  =  4 V + 4 V
            6k + 3k          6k + 3k
     = 8 V
```

## 테브난과 노턴

V<sub>th</sub>는 단자를 열었을 때의 전압 V<sub>oc</sub>이고, R<sub>th</sub>는 독립 전원을 모두 끄고 단자에서 들여다본 저항이다. 예제에서는 Vs가 단락, Is가 개방되므로 R<sub>th</sub> = (6 kΩ∥3 kΩ) + 1 kΩ = 3 kΩ이다. 검산으로 단자를 단락시키면 노드 a의 KCL에서 V<sub>a</sub> = 8/3 V, 단락 전류 I<sub>sc</sub> = V<sub>a</sub>/1 kΩ = 2.67 mA이고, V<sub>oc</sub>/I<sub>sc</sub> = 8 V / 2.67 mA = 3 kΩ으로 같다.

종속 전원이 있으면 직병렬 합성만으로는 R<sub>th</sub>가 나오지 않는다. 그때는 V<sub>oc</sub>/I<sub>sc</sub>를 쓰거나, 독립 전원만 끄고 종속 전원은 살려 둔 채 단자에 시험 전원(test source)을 걸어 R<sub>th</sub> = V<sub>test</sub>/I<sub>test</sub>로 구한다. 테브난 회로를 전원 변환(source transformation)하면 노턴 등가(Norton equivalent)가 된다: 전류원 I<sub>N</sub> = V<sub>th</sub>/R<sub>th</sub> = I<sub>sc</sub>에 같은 R<sub>th</sub>를 병렬로 단다.

```ascii
    R_th 3kΩ
  ┌──/\/\/──○ A            ┌──────┬─────○ A
 ┌┴┐                      ┌┴┐    ┌┴┐
 │+│ V_th      ≡      I_N │↑│    │ │ R_th
 │-│ 8V            2.67mA │ │    │ │ 3kΩ
 └┬┘                      └┬┘    └┬┘
  └─────────○ B            └──────┴─────○ B
```

그림. 위 회로를 A, B에서 본 테브난 등가와 노턴 등가. 어떤 부하를 달아도 원래 회로와 구별되지 않는다

## 직선 두 개의 교점

테브난 등가가 말하는 것은 결국 단자의 v-i 관계가 직선 v = V<sub>th</sub> − R<sub>th</sub>·i라는 것이다. 직선은 두 점이면 정해지니 개방(i = 0)과 단락(v = 0) 두 번만 재면 회로 내부를 몰라도 된다. 부하 R<sub>L</sub>을 달면 부하의 직선 v = R<sub>L</sub>·i와 만나는 점이 실제 동작점이다.

```ascii
  v [V]
   8 ┤●       /    load    v = R_L·i
     │ \     /
     │  \   /
     │   \ /
   4 ┤    ●        ← R_L = R_th: 4 V, 1.33 mA
     │   / \
     │  /   \
     │ /     \     source  v = 8 − 3kΩ·i
   0 └────────●──▶ i [mA]
      0      2.67
```

그림. 기울기 −R<sub>th</sub>인 전원 직선과 부하 직선의 교점이 동작점이다. 두 절편이 V<sub>th</sub> = 8 V와 I<sub>sc</sub> = 2.67 mA

부하가 받는 전력을 R<sub>L</sub>에 대해 미분해 0으로 놓으면 R<sub>L</sub> = R<sub>th</sub>에서 최대가 된다. 이것이 최대 전력 전달(maximum power transfer) 조건이다.

```eq
           V_th²·R_L               V_th²
P(R_L) = ─────────────    P_max = ──────  =  5.33 mW
         (R_th + R_L)²            4·R_th
```

이때 R<sub>th</sub>도 부하와 같은 전력을 소모하므로 등가회로로 따진 효율은 50 %다(등가는 단자 밖에서만 성립하므로 원래 회로 내부의 손실은 이와 다를 수 있다). 신호를 최대한 받아야 하는 안테나나 RF 정합에서는 이 조건을 쓰지만, 효율이 중요한 전력 공급에서는 쓰지 않는다. 덤으로 R<sub>L</sub> = 1 kΩ과 9 kΩ은 둘 다 4 mW를 받는데, R<sub>L1</sub>·R<sub>L2</sub> = R<sub>th</sub><sup>2</sup>인 두 부하는 항상 같은 전력을 받는다.

## 이어지는 곳

선형화 줄에서 앞 역은 [선형 시불변 시스템](/study/lti/)이다. 거기서 선형성을 가산성과 동차성, 곧 a·x<sub>1</sub> + b·x<sub>2</sub>를 넣으면 a·y<sub>1</sub> + b·y<sub>2</sub>가 나오는 성질로 정의했다. 중첩의 원리는 그 식을 회로에 그대로 쓴 것이다. 전원 하나를 끄는 것은 입력 하나를 0으로 두는 것이고, 응답을 더하는 것이 가산성이다. 그래서 다이오드처럼 비선형 소자가 하나만 들어가도 중첩은 깨진다.

다음 역은 [소신호 모델](/study/small-signal/)이다. 트랜지스터는 비선형이라 테브난을 바로 쓸 수 없지만, 동작점(Q-point) 근처에서 곡선을 접선으로 바꾸면 g<sub>m</sub>·v<sub>gs</sub> 같은 선형 종속 전원과 저항만 남는다. 그다음은 이 노트의 도구 그대로다. 직류 전원 V<sub>DD</sub>는 신호 성분이 0이라 꺼서 접지가 되고(전압원은 단락), 증폭기의 출력 저항은 출력 단자에서 본 R<sub>th</sub>, 입력 저항은 입력 단자에서 본 저항이다. 종속 전원이 있으니 시험 전원으로 구한다는 점까지 같다. 증폭기를 입력 저항, 출력 쪽 전압원 A<sub>vo</sub>·v<sub>in</sub>(A<sub>vo</sub>는 부하 없을 때의 이득), 출력 저항 R<sub>out</sub>으로 그리는 모델 자체가 테브난 등가이고, 다음 단을 달면 R<sub>out</sub>과 다음 단 입력 저항의 분압만큼 이득이 깎인다.

위 그림의 전원 직선은 처음부터 직선이었다. 소신호 모델은 휘어진 곡선의 한 점에서 그은 접선이고, 그 기울기 dy/dx가 g<sub>m</sub> = ∂i<sub>D</sub>/∂v<sub>GS</sub> 같은 숫자가 된다. 이 줄의 끝인 [역전파](/study/backprop/)는 그런 국소 기울기를 곱해서 잇는 일이다.
