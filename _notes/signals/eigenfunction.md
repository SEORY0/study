복소지수 e<sup>st</sup>는 LTI 시스템을 지나도 모양이 바뀌지 않는다. 바뀌는 것은 앞에 곱해지는 복소수 하나뿐이고, 그 복소수가 전달함수(transfer function) H(s)다. 행렬 A에 고유벡터(eigenvector)를 넣으면 같은 방향의 벡터가 λ배 되어 나오는 것과 같은 구조라서, e<sup>st</sup>를 LTI 시스템의 고유함수(eigenfunction)라 부른다. 신호를 복소지수로 쪼개는 푸리에 변환과 라플라스 변환이 쓸모 있는 이유가 전부 여기서 나온다.

## 넣어 보기

컨볼루션 식에 x(t) = e<sup>st</sup>를 넣는다(s는 아래 적분이 수렴하는 범위의 복소수).

```eq
          ∞
y(t)  =   ∫  h(τ)·e^(s(t−τ)) dτ
         −∞
                    ∞
      =  e^(st)  ·  ∫  h(τ)·e^(−sτ) dτ
                   −∞
      =  H(s)·e^(st)
```

둘째 줄의 적분에는 t가 없으므로 그냥 복소수이고, 그것을 H(s)라 부른다. h(t)를 알면 정해지는 s의 함수다.

핵심은 한 걸음, e<sup>s(t−τ)</sup> = e<sup>st</sup>·e<sup>−sτ</sup>다. 지수함수는 늦추는 것이 상수를 곱하는 것과 같다. LTI 시스템이 하는 일은 입력을 여러 시간만큼 늦춘 것들의 가중합(컨볼루션)이니, 늦춰도 모양이 그대로인 함수는 가중합을 해도 모양이 그대로다. 미분도 마찬가지로 d/dt e<sup>st</sup> = s·e<sup>st</sup>다. 실수 사인은 다르다. sin(t − τ) = sin t·cos τ − cos t·sin τ라서 늦추면 sin과 cos가 섞이고, sin t의 상수배로 쓸 수 없다. 그래서 고유함수는 실수 사인이 아니라 복소지수다.

## 고유벡터와 나란히

```ascii
 linear algebra         LTI system
 ────────────────────   ───────────────────────
 matrix A               system h(t)
 eigenvector v          e^(st)
 A·v = λ·v              h * e^(st) = H(s)·e^(st)
 eigenvalue λ           H(s)
 x = sum of v's         x(t) = sum of e^(st)'s
```

그림. 행렬의 고유벡터와 LTI 시스템의 고유함수

행렬에서 x를 고유벡터들의 합으로 쪼개 두면 A·x는 성분마다 λ를 곱하는 일로 끝난다(대각화, diagonalization). 신호도 같다. x(t)를 e<sup>st</sup>들의 합으로 쪼개 두면 시스템 통과는 성분마다 H(s)를 곱하는 일이다. 쪼개는 방법이 푸리에 변환(s = jω만 사용)과 라플라스 변환(s 전체)이다.

## 정현파가 지나갈 때

s = jω로 두면(안정한 시스템이라 jω 축에서 적분이 수렴할 때) H(jω)는 주파수 응답(frequency response)이다. cos(ωt)는 e<sup>jωt</sup>와 e<sup>−jωt</sup>의 평균이고, h(t)가 실수이면 H(−jω)는 H(jω)의 켤레복소수라서 두 성분의 출력을 더하면 다시 실수 cos 하나가 된다.

```eq
cos(ωt)   →   |H(jω)| · cos(ωt + ∠H(jω))
```

주파수는 그대로, 크기는 |H(jω)|배, 위상은 ∠H(jω)만큼 밀린다. 주파수 응답을 측정한다는 것은 이 두 숫자를 ω마다 재는 일이고, 회로 실험에서 함수발생기로 사인을 넣고 오실로스코프로 진폭비와 시간차를 읽는 것이 정확히 이 작업이다. 출력이 Δt 늦게 나오면 위상은 −ω·Δt다. 거꾸로 출력에 입력에 없던 주파수가 나타난다면 그 시스템은 LTI가 아니라는 증거다(왜곡, 클리핑). 고유함수가 아닌 입력은 성분마다 다른 H를 곱받아 모양 자체가 바뀐다.

```ascii
             ┌────────┐
 e^(st)  ──▶ │        │ ──▶ H(s)·e^(st)
 cos(ωt) ──▶ │  h(t)  │ ──▶ |H|·cos(ωt + ∠H)
 square  ──▶ │        │ ──▶ not a square
             └────────┘
```

그림. 복소지수는 숫자 하나만 곱해져 나오고, 사각파는 성분마다 다른 배율을 받아 다른 모양으로 나온다

RC 저역통과 회로로 숫자를 넣어 본다. h(t) = (1/RC)·e<sup>−t/RC</sup>·u(t)를 위 적분에 넣으면 H(s) = 1/(1 + sRC)이다. 적분이 수렴하려면 Re{s} > −1/RC여야 하는데, 이렇게 s마다 적분이 수렴하는 범위를 따지는 것이 라플라스 변환의 수렴 영역(ROC, region of convergence)이다. RC = 1 ms, ω = 1000 rad/s(약 159 Hz)이면 H(j1000) = 1/(1 + j) = 0.5 − j0.5, 크기 0.707, 위상 −45°다. 입력 cos(1000t)는 0.707·cos(1000t − 45°)로 나온다. ω를 10배 올리면 1/(1 + j10)이라 크기 0.0995, 위상 −84.3°로 거의 다 깎인다. ω가 0에서 ∞로 가는 동안 H(jω)는 복소평면에서 1을 떠나 원점으로 가는 반원(중심 0.5, 반지름 0.5, 아래쪽 절반)을 그린다.

```ascii
        ▲ Im
  ω→∞   │                              ω=0
 ───────●───────────────────────────────●────▶ Re
        │                               ·
        │·                             ·
        │·                             ·
        │ ··                         ··
        │   ·                       ·
        │    ···                 ···
        │       ·····       ·····
        │            ···●···   ωRC = 1
```

그림. RC 저역통과의 H(jω) 자취. 1에서 출발해 반원의 맨 아래(ωRC = 1, 0.5 − j0.5)를 지나 원점으로 간다

## 이어지는 곳

복소지수 줄(cexp)의 앞 역은 [오일러 공식](/study/euler/)이다. 거기서 본 d/dt e<sup>jωt</sup> = jω·e<sup>jωt</sup>, 즉 미분이 90° 회전과 ω배라는 사실이 여기서는 "미분뿐 아니라 어떤 LTI 연산도 e<sup>st</sup>에 숫자 하나를 곱할 뿐"으로 넓어진다. 근거는 같은 지수법칙 e<sup>a+b</sup> = e<sup>a</sup>·e<sup>b</sup>다.

다음 역은 [페이저](/study/phasor/)다. 회로가 한 주파수 ω의 정현파로 구동되는 정상상태(steady state)에서는 모든 전압과 전류가 같은 e<sup>jωt</sup>에 각자의 복소수를 곱한 것의 실수부이고, 그 복소수가 페이저(phasor)다. 인덕터 v = L·di/dt에 i = I·e<sup>jωt</sup>를 넣으면 v = jωL·I·e<sup>jωt</sup>, 즉 V = jωL·I다. 이 노트의 y = H(s)·e<sup>st</sup>에 s = jω를 넣은 것을 소자 하나하나에 적용한 것이 페이저 해석이고, 그래서 회로의 미분방정식이 복소수 사칙연산이 된다. 위의 0.707∠−45°도 페이저로 계산하면 한 줄에 나온다. 같은 성질은 이 줄의 끝 [OFDM](/study/ofdm/)에서 Y<sub>k</sub> = H<sub>k</sub>·X<sub>k</sub>라는 모습으로 다시 나온다. H(s)는 h(t)의 [라플라스 변환](/study/laplace/)이고, H(jω)는 h(t)의 [푸리에 변환](/study/fourier-transform/)이다.
