컨볼루션(convolution)은 LTI 시스템에서 입력과 임펄스 응답(impulse response)으로 출력을 계산하는 연산이다. 입력을 시간축 위의 임펄스 조각들로 쪼개면 각 조각은 자기 크기만큼 키운 h를 자기 시각만큼 늦춰 내보내고, 출력은 그것들의 합이다. h 하나만 알면 어떤 입력에 대한 출력도 나온다는 것이 핵심이다.

## 정의

```eq
          ∞
y[n]  =   ∑   x[k] · h[n − k]     =  (x * h)[n]
        k=−∞

          ∞
y(t)  =   ∫   x(τ) · h(t − τ) dτ  =  (x * h)(t)
         −∞
```

이산식은 한 줄로 읽힌다. 시각 k에 들어온 크기 x[k]짜리 임펄스는 n − k만큼 지난 시각 n에 x[k]·h[n − k]를 남기고, y[n]은 모든 k가 남긴 것을 더한 값이다. 연속식은 합이 적분으로, k가 τ로 바뀌었을 뿐이다. 변수를 바꾸면 x ∗ h = h ∗ x(교환법칙)이므로 어느 쪽을 뒤집어도 된다. 길이 N과 M인 수열을 컨볼루션하면 길이 N + M − 1이 나온다.

h의 모양에는 시스템의 성질이 그대로 적혀 있다. n < 0에서 h[n] = 0이면 y[n]은 현재와 과거 입력만 쓰는 인과(causal) 시스템이고, 실시간으로 동작하는 회로와 필터는 모두 이 조건을 만족한다. h가 0이 아닌 구간의 길이는 시스템이 입력을 기억하는 길이다. 3점 이동평균은 샘플 3개를 기억하고, RC 회로는 이론상 영원히 기억하지만 시상수(time constant) τ = RC의 5배가 지나면 영향이 e<sup>−5</sup> ≈ 0.7 %로 줄어 사실상 잊는다.

## 퍼뜨려서 더하기

x[n] = {1, 2, 3}, h[n] = {2, 1}로 직접 해 본다(둘 다 n = 0부터). h는 처음에 2, 다음에 1로 줄어드는 아주 거친 감쇠 응답이다. 입력 쪽에서 보면 각 샘플이 자기 몫의 h를 퍼뜨린다.

```ascii
 n             0   1   2   3
 x[0]·h[n]     2   1             x[0] = 1
 x[1]·h[n−1]       4   2         x[1] = 2
 x[2]·h[n−2]           6   3     x[2] = 3
 ───────────────────────────
 y[n]          2   5   8   3
```

그림. 입력 샘플마다 크기를 곱한 h를 그 시각에 놓고 세로로 더한다

## 뒤집고 밀기

출력 쪽에서 보면 같은 계산이 "뒤집고 밀고 곱해서 더하기"(flip and slide)다. h[n − k]를 k의 함수로 보면 h를 좌우로 뒤집은 다음 n만큼 오른쪽으로 민 것이다. n마다 x[k]와 겹치는 칸끼리 곱해 더하면 y[n]이 하나씩 나온다. 뒤집는 이유는 시각 n에서 가장 최근 입력 x[n]은 방금 들어왔으니 h[0]을, 한 칸 전 입력 x[n − 1]은 h[1]을 곱받기 때문이다. 입력은 과거에서 현재 순으로 늘어서 있고 h는 현재에서 과거 순으로 대야 하니, 둘을 나란히 놓으면 한쪽이 뒤집힌다.

```ascii
 k            −1   0   1   2   3
 x[k]              1   2   3
 h[0−k]        1   2               → 1·2       = 2
 h[1−k]            1   2           → 1·1 + 2·2 = 5
 h[2−k]                1   2       → 2·1 + 3·2 = 8
 h[3−k]                    1   2   → 3·1       = 3
```

그림. 뒤집힌 h(왼쪽부터 1, 2)가 한 칸씩 오른쪽으로 미끄러진다

두 그림의 답은 같다: y = {2, 5, 8, 3}. 검산은 합끼리 곱하면 된다. ∑y = ∑x · ∑h = 6 × 3 = 18이고, 실제로 2 + 5 + 8 + 3 = 18이다. 코드로는 `numpy.convolve([1, 2, 3], [2, 1])` 한 줄이다. 첫 그림은 "입력 하나가 출력 여러 개에 영향을 준다", 둘째 그림은 "출력 하나가 입력 여러 개를 모은다"는 같은 합의 두 가지 읽기다.

## 이동평균

h[n] = 1/3(n = 0, 1, 2)이면 y[n] = (x[n] + x[n − 1] + x[n − 2])/3, 3점 이동평균(moving average)이다. 계단 입력 u[n]을 넣으면 출력은 1/3, 2/3, 1로 세 샘플에 걸쳐 올라가 1에 머문다. 급하게 꺾인 입력이 무뎌진다는 점에서 RC 회로의 충전과 닮았다. 다만 여기서는 직선으로, RC에서는 지수 곡선으로 오른다. 반대로 가장 빨리 흔들리는 이산 신호 (−1)<sup>n</sup> = 1, −1, 1, …을 계속 넣으면 세 항 중 둘이 상쇄되어 출력 크기가 (1 − 1 + 1)/3 = 1/3로 준다. 느린 변화는 통과시키고 빠른 변화는 깎는 저역통과 필터(low-pass filter)다.

(−1)<sup>n</sup>이 모양은 그대로 두고 1/3배만 되어 나온 것처럼, 한 주파수의 성분은 그 주파수에서 정해진 숫자 하나만 곱받는다. 이것을 모든 주파수에 한꺼번에 적은 것이 컨볼루션 정리(convolution theorem)다. 시간에서 y = x ∗ h이면 주파수에서 Y(jω) = X(jω)·H(jω)이고, 컨볼루션 합이 주파수마다 곱셈 하나가 된다. 이 이야기는 [푸리에 변환](/study/fourier-transform/)에서 이어지고, 정현파가 숫자 하나만 곱받고 나오는 이유는 [복소지수와 고유함수](/study/eigenfunction/)에 있다.

## 이어지는 곳

컨볼루션 줄(conv)에서 앞 역은 [선형 시불변 시스템](/study/lti/)이다. 퍼뜨려서 더하기 그림의 각 행이 같은 모양 h를 늦춰 쓰는 것은 시불변성이고, 행들을 세로로 더해도 되는 것은 선형성이다. 둘 중 하나만 빠져도 이 표는 쓸 수 없다.

다음 역은 [RC 과도응답](/study/rc-transient/)이다. 커패시터 전압을 출력으로 하는 RC 저역통과 회로의 임펄스 응답은 h(t) = (1/RC)·e<sup>−t/RC</sup>·u(t)로, 위의 거친 {2, 1}을 연속으로 매끄럽게 만든 감쇠 응답이다. 그래서 이 회로의 어떤 입력에 대한 응답도 x ∗ h로 구한다. 계단 입력이면 u(t)와 h의 컨볼루션은 h를 0부터 t까지 적분한 것이 되고, 결과는 1 − e<sup>−t/RC</sup>, t = RC에서 63.2 %에 이르는 익숙한 충전 곡선이다. 이 줄의 끝 [CNN 합성곱](/study/cnn/)은 같은 합을 2차원 이미지에 쓰는데, 커널을 뒤집지 않고 값을 학습으로 정한다는 점만 다르다.
