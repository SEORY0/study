샘플링(sampling)은 연속 신호 x(t)를 T<sub>s</sub> 간격으로 찍어 숫자열 x[n] = x(nT<sub>s</sub>)로 바꾸는 일이다. 주파수 영역에서 보면 샘플링은 스펙트럼을 f<sub>s</sub> = 1/T<sub>s</sub>마다 복사하는 연산이고, 샘플링 정리(sampling theorem)는 그 복사본들이 겹치지 않을 조건이다. 겹치지 않았다면 숫자열만으로 원래 신호를 정확히 되살릴 수 있고, 겹쳤다면 무엇을 해도 되살릴 수 없다.

## 임펄스열 곱하기

찍는 동작을 x(t)에 임펄스열 p(t)를 곱하는 것으로 모델링한다. p(t)는 주기 T<sub>s</sub>인 주기 신호라 푸리에 급수 계수가 모두 1/T<sub>s</sub>로 같고, 그래서 그 변환은 ω<sub>s</sub> = 2π/T<sub>s</sub> 간격의 임펄스열이다. 시간의 곱셈은 주파수의 컨볼루션이고, 임펄스와 컨볼루션하면 그 자리로 복사되므로 다음이 나온다.

```eq
           ∞
p(t)   =   ∑   δ(t − n·T_s)
         n=−∞
                       ∞
X_s(jω)  =  (1/T_s) ·  ∑   X(j(ω − k·ω_s))
                     k=−∞
```

원래 스펙트럼이 |f| ≤ f<sub>max</sub> 안에 갇혀 있는 대역 제한(band-limited) 신호라면 바로 옆 복사본은 f<sub>s</sub> − f<sub>max</sub>에서 시작한다. 이것이 f<sub>max</sub>보다 커야 겹치지 않으므로 조건은 f<sub>s</sub> > 2·f<sub>max</sub>다. 2·f<sub>max</sub>를 나이퀴스트율(Nyquist rate), f<sub>s</sub>/2를 나이퀴스트 주파수(Nyquist frequency)라 부른다.

```ascii
 fs > 2·fmax
              ┌╌╌╌ ideal LPF ╌╌╌╌┐
     /\       ┆        /\        ┆       /\
    /  \      ┆       /  \       ┆      /  \
   /    \     ┆      /    \      ┆     /    \
  /      \    ┆     /      \     ┆    /      \
 /        \   ┆    /        \    ┆   /        \
 ─────────────┴──────────────────┴─────────────▶ f
    −fs     −fs/2      0        fs/2     fs
```

그림. 복사본 사이에 틈이 있어서 ±f<sub>s</sub>/2에서 자르는 저역통과 필터로 가운데만 남길 수 있다

```ascii
 fs < 2·fmax                         ▒ : overlap
       /\      /\      /\      /\      /\
      /  \    /  \    /  \    /  \    /  \
     /    \  /    \  /    \  /    \  /    \
    /      \/      \/      \/      \/      \
   /       /\      /\      /\      /\       \
  /       /▒▒\    /▒▒\    /▒▒\    /▒▒\       \
 ──────────────────────────────────────────────▶ f
      −2fs    −fs      0       fs     2fs
```

그림. f<sub>s</sub>가 작으면 이웃 복사본의 꼬리가 둘 사이의 경계 ±f<sub>s</sub>/2를 넘어 겹친다. 겹친 부분(▒)은 어느 필터로도 다시 가를 수 없다

조건에 등호가 빠진 이유도 있다. 정확히 f<sub>s</sub>/2인 사인을 0을 지나는 순간마다 찍으면 sin(πn) = 0이라 샘플이 전부 0이다.

## 앨리어싱

복사본이 겹치면 f<sub>s</sub>/2 위의 성분이 아래로 접혀 들어와 원래 있던 성분과 구별할 수 없게 섞인다. 이것이 앨리어싱(aliasing)이다. f<sub>s</sub> = 1 kHz로 700 Hz 코사인을 찍으면 cos(2π·0.7n) = cos(2π·(1 − 0.3)n) = cos(2π·0.3n)이라, 300 Hz 코사인을 찍은 것과 샘플이 하나도 다르지 않다. 1300 Hz도 마찬가지다.

```ascii
 n              0       1       2       3       4
 300 Hz     1.000  −0.309  −0.809   0.809   0.309
 700 Hz     1.000  −0.309  −0.809   0.809   0.309
 1300 Hz    1.000  −0.309  −0.809   0.809   0.309
```

그림. f<sub>s</sub> = 1 kHz에서 세 코사인의 샘플. 숫자열만 보고는 셋을 가를 수 없다

일반적으로 샘플만 보면 주파수 f인 정현파는 |f − k·f<sub>s</sub>|(k는 정수) 가운데 0과 f<sub>s</sub>/2 사이에 드는 주파수의 정현파로 보인다. 위 예에서는 |700 − 1000| = 300, |1300 − 1000| = 300이다. 그래서 샘플링 전에 f<sub>s</sub>/2 위를 아날로그 앤티앨리어싱 필터(anti-aliasing filter)로 먼저 잘라야 하고, 한 번 접혀 들어온 성분은 나중에 디지털로 뺄 방법이 없다.

숫자열의 주파수가 −f<sub>s</sub>/2에서 f<sub>s</sub>/2 사이에서만 의미가 있는 것도 같은 이유다. 이산 신호에서는 각주파수를 샘플당 회전각 Ω = ω·T<sub>s</sub>로 재고, Ω는 2π마다 같은 신호를 가리키므로 −π에서 π까지만 쓴다. 가장 빠른 이산 신호는 Ω = π, 즉 f<sub>s</sub>/2에서 샘플마다 반 바퀴씩 도는 (−1)<sup>n</sup>이다. [컨볼루션](/study/convolution/)의 이동평균이 1/3로 깎았던 그 신호다.

## 되살리기

복사본이 떨어져 있으면 차단 주파수 f<sub>s</sub>/2, 이득 T<sub>s</sub>인 이상적 저역통과 필터로 가운데 복사본만 남겨 X(jω)를 그대로 돌려받는다. 이 필터는 주파수에서 사각형이라 시간에서는 sinc이고, 시간 영역에서 보면 샘플마다 sinc를 하나씩 세워 더하는 보간(interpolation)이다.

```eq
          ∞             sin(π(t − nT_s)/T_s)
x(t)  =   ∑   x[n] ·  ────────────────────────
        n=−∞               π(t − nT_s)/T_s
```

각 sinc는 자기 샘플 시각에서 1이고 다른 모든 샘플 시각에서 0이라, 이 합은 샘플 값을 정확히 지나면서 그 사이를 대역 제한된 유일한 곡선으로 메운다. 실제 DAC는 값을 다음 샘플까지 붙잡아 두는 영차 유지(zero-order hold) 계단 뒤에 아날로그 저역통과 필터를 붙여 이것을 근사한다.

## 이어지는 곳

주파수 영역 줄(freq)의 앞 역은 [푸리에 변환](/study/fourier-transform/)이다. 쓰인 재료는 둘이다. 곱셈 ↔ 컨볼루션 성질이 임펄스열을 곱하면 스펙트럼이 복사된다는 결론을 주고, 사각형 ↔ sinc 쌍이 되살리는 필터를 시간에서 sinc로 만든다. [푸리에 급수](/study/fourier-series/)에서 본 "주기적이면 이산적"은 여기서 "이산적이면 주기적"으로 뒤집혀 나타난다. X<sub>s</sub>(jω)가 ω<sub>s</sub> 주기로 반복되는 것이 그 모습이다.

다음 역은 [디지털 오디오](/study/digital-audio/)다. 사람이 듣는 상한을 약 20 kHz로 잡으면 나이퀴스트율은 40 kHz이고, CD의 44.1 kHz는 거기에 20 kHz에서 22.05 kHz 사이의 여유를 더해 앤티앨리어싱 필터가 꺾일 자리를 남긴 값이다. 위의 접힘 공식 |f − k·f<sub>s</sub>|도 그대로 쓰여, 걸러지지 않은 초음파 성분이 가청 대역 어디로 떨어지는지를 계산하게 된다.
