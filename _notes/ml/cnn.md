합성곱 신경망(CNN, convolutional neural network)의 합성곱 층은 2차원 이산 [컨볼루션](/study/convolution/)이다. 3×3 같은 작은 커널(kernel)을 이미지 위로 한 칸씩 밀면서 겹친 칸끼리 곱해 더한다. y[n] = ∑x[k]h[n−k]에서 인덱스가 두 개가 되었을 뿐이고, 새로운 점은 h를 사람이 설계하지 않고 [역전파](/study/backprop/)로 학습한다는 것 하나다.

## 컨볼루션과 상호상관

```eq
y[m,n] = ∑ ∑ x[i,j]·h[m-i, n-j]        (conv)
         i j

y[m,n] = ∑ ∑ x[m+i, n+j]·w[i,j]        (corr)
         i j
```

PyTorch의 `Conv2d`를 비롯한 딥러닝 라이브러리는 커널을 뒤집지 않는 아래 식, 곧 상호상관(cross-correlation)을 계산하면서도 이름은 합성곱이라 부른다. 커널을 학습하므로 상관없다. 뒤집힌 커널이 필요하면 네트워크가 뒤집힌 값을 배운다. 손으로 설계한 커널을 옮겨 올 때만 조심하면 되는데, 아래의 Sobel 커널은 180° 돌리면(가로와 세로를 모두 뒤집으면) 부호만 바뀐다.

## 한 칸 계산

5×5 이미지의 왼쪽 세 열은 밝기 1, 오른쪽 두 열은 8이다. 세로 경계를 찾는 Sobel-x 커널을 가운데 칸에 대 본다.

```ascii
 x (5×5)
   1   1   1   8   8
     ┌───────────┐          w (Sobel-x)
   1 │ 1   1   8 │ 8        -1   0  +1
   1 │ 1   1   8 │ 8    ×   -2   0  +2
   1 │ 1   1   8 │ 8        -1   0  +1
     └───────────┘        sum ──▶ y[1,1] = 28
   1   1   1   8   8

 y (3×3)   0  28  28
           0 [28] 28
           0  28  28
```

그림. 상자 안 9칸과 커널을 칸끼리 곱해 더한 값이 출력의 가운데 칸이다

```eq
y[1,1] = (-1)·1 + 0·1 + (+1)·8
       + (-2)·1 + 0·1 + (+2)·8
       + (-1)·1 + 0·1 + (+1)·8
       = 7 + 14 + 7 = 28
```

출력의 왼쪽 열은 0이다. Sobel-x는 세로로는 [1 2 1]로 평활하고 가로로는 [−1 0 1]로 차분하는 커널이라 가중치 합이 0이다. 그래서 평평한 곳에서는 0을 내고 밝기가 바뀌는 곳에서만 반응한다. 주파수로 말하면 DC 이득이 0인 미분기다. 반대로 블러(blur) 커널 (1/16)·[1 2 1; 2 4 2; 1 2 1]은 가중치 합이 1이라 평평한 곳은 그대로 두고 경계만 뭉갠다. 1차원 가중 이동 평균 [1 2 1]/4를 가로와 세로로 곱한 저역통과 필터다. 학습을 마친 CNN의 첫 층 커널을 그려 보면 여러 방향의 경계 검출기와 색 얼룩처럼 생긴 것이 많다. 사람이 설계하던 필터를 데이터가 다시 찾아낸 셈이다.

출력 크기는 입력 N, 커널 K, 패딩(padding) P, 스트라이드(stride) S에 대해 (N + 2P − K)/S + 1이다(나누어떨어지지 않으면 내림). 여기서는 (5 − 3)/1 + 1 = 3이다. 가장자리에 0을 한 겹 두르면(P = 1) 5×5가 유지되고, 패딩 없이 두 칸씩 뛰면(S = 2) 2×2가 된다.

## 가중치 공유와 이동

커널의 9개 값은 이미지의 모든 위치에서 같다. 이것이 가중치 공유(weight sharing)이고, 신호및시스템 말로는 시불변성(shift invariance)이다. 그 결과로 이동 등변성(translation equivariance)이 따라온다. 입력을 한 칸 옮기면 출력도 한 칸 옮겨진다(스트라이드 1, 가장자리 제외). 고양이가 왼쪽 위에 있든 오른쪽 아래에 있든 같은 커널이 같은 특징을 잡는다.

실제 층은 입력이 여러 장(채널)이다. RGB 입력이면 커널도 3×3×3이고, 채널마다 2차원 상호상관을 한 뒤 모두 더하고 편향(bias)을 더해 출력 한 장을 만든다. 출력 채널 수만큼 이런 커널을 둔다.

파라미터 수도 줄어든다. 5×5 입력에서 3×3 출력으로 가는 완전연결 층(fully connected layer)에는 가중치가 25 × 9 = 225개 필요하지만, 합성곱 층은 9개다. 224×224 RGB 이미지에서 3×3 커널 64장을 써도 3·3·3·64 = 1,728개(편향 64개 별도)로, 이미지 크기와 무관하다.

## 층 사이의 ReLU

합성곱 층만 쌓으면 깊이가 의미 없다. 컨볼루션은 결합법칙이 성립해서 (x∗h<sub>1</sub>)∗h<sub>2</sub> = x∗(h<sub>1</sub>∗h<sub>2</sub>)이고, 3×3 두 장은 5×5 한 장과 같다. 그래서 층 사이에 ReLU, 곧 max(0, z)를 넣어 중첩의 원리를 일부러 깬다. CNN은 LTI 필터와 기억 없는 비선형 함수를 번갈아 쌓은 구조다. 3×3을 두 번 거치면 출력 한 칸이 보는 영역(receptive field)은 5×5로 넓어지지만, 사이의 ReLU 덕분에 이것은 더 이상 5×5 선형 필터 하나로 줄어들지 않는다.

## 이어지는 곳

컨볼루션 줄에서 바로 앞은 [RC 과도응답](/study/rc-transient/)이고, 이 노트가 마지막 역이다. RC 회로의 출력도 입력과 임펄스 응답의 컨볼루션이었고, 그 커널 h(t) = (1/RC)e<sup>−t/RC</sup>u(t)는 R과 C라는 물리가 정해 준다. 이 커널은 넓이가 1이라 DC 이득 1인 평활 필터, 곧 위의 블러 커널과 같은 종류다. 다만 과거만 보는 한쪽짜리(인과) 블러다. t = 0, τ, 2τ에서 샘플하면 가중치는 1 : 0.368 : 0.135로 지수적으로 줄어든다. CNN은 이 가중치를 물리 대신 데이터로 정할 뿐, 밀어서 곱하고 더하는 계산은 같다.

더 거슬러 가면 [컨볼루션](/study/convolution/)의 뒤집고 밀기와 이동 평균이 여기서 2차원 블러가 되었다. [선형 시불변 시스템](/study/lti/)의 두 가정은 서로 다른 운명을 맞는다. 시불변성은 가중치 공유로 그대로 남고, 선형성은 ReLU가 일부러 깬다.

커널을 배우는 [역전파](/study/backprop/)에서도 같은 연산이 다시 나온다. 위의 상호상관 식을 w로 미분하면 ∂L/∂w[i,j] = ∑<sub>m,n</sub> x[m+i, n+j]·∂L/∂y[m,n], 곧 입력과 출력 기울기의 상호상관이 커널의 기울기다.
