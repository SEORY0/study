디지털 오디오는 두 번 자른다. 시간 축을 자르는 샘플링과 세로 축을 자르는 양자화(quantization)다. CD의 44.1 kHz와 16 bit는 각각 [샘플링 정리](/study/sampling/)의 f<sub>s</sub> > 2·f<sub>max</sub>와 양자화 잡음 계산에서 나온 숫자다. 둘 중 무서운 쪽은 샘플링이다. 양자화 잡음은 작게 깔릴 뿐이지만, 앨리어싱(aliasing)은 원래 없던 음을 만들어 낸다.

## 왜 44.1 kHz인가

사람 귀는 대략 20 kHz까지 듣는다. 그러면 40 kHz로 충분해 보이지만, 그러려면 20 kHz는 그대로 통과시키고 그 바로 위는 완전히 막는 벽 같은 아날로그 필터가 ADC 앞에 있어야 한다. 44.1 kHz는 그 필터에 숨 쉴 틈을 준다. 앨리어싱을 아예 없애려면 f<sub>s</sub>/2 = 22.05 kHz부터 막아야 하고, 가청 대역으로 접혀 들어오는 것만 막겠다고 해도 f<sub>s</sub> − 20 kHz = 24.1 kHz부터는 막아야 한다. 어느 쪽이든 주파수가 1.1에서 1.2배 오르는 사이에 수십 dB가 떨어져야 하니, 아날로그로는 아주 고차 필터다.

44,100이라는 숫자 자체는 초기 디지털 녹음이 PCM 데이터를 비디오테이프에 저장하던 데서 왔다. NTSC는 60 필드 × 245 줄 × 3 샘플, PAL은 50 필드 × 294 줄 × 3 샘플로 둘 다 44,100이다. 영상과 방송은 48 kHz를 쓰고, 그만큼 전이 대역(transition band)도 20에서 24 kHz로 조금 넉넉하다.

## 접힘

30 kHz 사인파를 44.1 kHz로 샘플링해 본다. 정수 n에 대해 e<sup>j2πn</sup> = 1이므로, 주파수에서 f<sub>s</sub>를 빼도 샘플은 하나도 바뀌지 않는다.

```eq
cos(2π·30000·n/44100)
  = cos(2π·(30000 - 44100)·n/44100)
  = cos(2π·14100·n/44100)
```

cos은 짝함수라 −14.1 kHz는 14.1 kHz와 같다. 샘플만 보고는 30 kHz와 14.1 kHz를 구별할 방법이 없다. 일반적으로 주파수 f는 |f − m·f<sub>s</sub>|(m은 f/f<sub>s</sub>에 가장 가까운 정수)로 보인다. 입력 주파수를 0부터 올리면 겉보기 주파수는 22.05 kHz에서 꺾여 내려오고, 44.1 kHz에서 0을 찍은 뒤 다시 올라간다. 주파수 축을 f<sub>s</sub>/2마다 병풍처럼 접는 것과 같다.

```ascii
      ▲ f_out (kHz)          f_s = 44.1 kHz
22.05 ┤                /\
      │              /    \
      │            /        \
 14.1 ┼┄┄┄┄┄┄┄┄┄┄●┄┄┄┄┄┄┄┄┄┄┄┄●
      │        / ┆            ┆ \
      │      /   ┆            ┆   \
      │    /     ┆            ┆     \          /
      │  /       ┆            ┆       \      /
      │/         ┆            ┆         \  /
    0 └──────────┴────────────┴─────────────────▶
                14.1  22.05   30        44.1  f_in
```

그림. 입력 주파수와 샘플링 뒤의 겉보기 주파수. 같은 가로선 위의 두 점은 샘플로 구별되지 않는다

스펙트럼으로 말하면, 샘플링은 f<sub>s</sub>마다 복제본을 찍는다. 실수 코사인의 +30 kHz 선은 f<sub>s</sub>만큼 내려와 −14.1 kHz에, −30 kHz 선은 f<sub>s</sub>만큼 올라와 +14.1 kHz에 떨어진다. 일단 기저대역(baseband) 안에 들어오면 진짜 14.1 kHz와 섞여서 어떤 디지털 필터로도 떼어 낼 수 없다. 그래서 앤티앨리어싱 필터(anti-aliasing filter)는 반드시 ADC 앞, 아날로그 쪽에 있어야 한다.

같은 일이 디지털 합성에서도 일어난다. 44.1 kHz에서 5 kHz 사각파를 매 샘플 ±1로 그냥 찍으면 홀수 고조파 25, 35, 45 kHz가 각각 19.1, 9.1, 0.9 kHz로 접힌다. 진폭은 기본파의 1/5, 1/7, 1/9(−14, −17, −19 dB)로 작지 않고, 5 kHz의 정수배가 아니라서 음정과 상관없는 지저분한 소리로 들린다.

## 오버샘플링과 시그마-델타

요즘 오디오 ADC는 대부분 시그마-델타(sigma-delta, ΣΔ) 방식이고, 먼저 오버샘플링(oversampling)한다. 예를 들어 44.1 kHz의 64배인 2.8224 MHz로 1비트(또는 몇 비트)짜리 거친 양자화기를 돌리고, 노이즈 셰이핑(noise shaping)으로 양자화 잡음을 가청 대역 밖 높은 주파수로 밀어낸다. 그다음 디지털 데시메이션(decimation) 필터가 20 kHz 위를 가파르게 잘라 내고 44.1 kHz로 솎아 낸다.

이러면 벽 같은 필터가 디지털 쪽으로 옮겨 간다. 아날로그 필터는 가청 대역으로 접혀 들어올 수 있는 성분, 곧 2.8224 MHz − 20 kHz ≈ 2.80 MHz 근처 위만 막으면 된다.

```ascii
 sampling at       pass up to  stop from  ratio
 ────────────────  ──────────  ─────────  ─────
 44.1 kHz          20 kHz      24.1 kHz    ×1.2
 2.8224 MHz (64×)  20 kHz      2.80 MHz    ×140
```

그림. 가청 대역(20 kHz 이하)으로 접혀 들어오는 것을 막기 위해 아날로그 필터가 넘어야 하는 전이 대역

디지털 필터에는 부품 오차도 온도 드리프트도 없고, 계수가 대칭인 FIR로 만들면 위상까지 정확히 선형이다.

## 16 bit와 98 dB

N비트 양자화기의 계단은 Δ = 2A/2<sup>N</sup>이고, 오차가 ±Δ/2 안에 고르게 퍼지면 잡음 전력은 Δ<sup>2</sup>/12다. 진폭 A인 정현파의 전력 A<sup>2</sup>/2와 비교하면 다음과 같다.

```eq
        A²/2      3
SNR = ──────── = ───·2^(2N)
       Δ²/12      2

SNR(dB) = 10·log₁₀(1.5·2^(2N)) = 6.02·N + 1.76
```

N = 16이면 98.1 dB다. 비트 하나는 진폭 2배, 곧 20·log<sub>10</sub>2 = 6.02 dB다. 오버샘플링만으로는 샘플링 주파수를 2배 올릴 때마다 대역 안 잡음이 3 dB씩 줄 뿐이지만, 노이즈 셰이핑이 잡음을 대역 밖으로 몰아내기 때문에 1비트 양자화기로도 16비트를 넘는 SNR이 나온다.

## 이어지는 곳

주파수 영역 줄에서 바로 앞은 [샘플링 정리](/study/sampling/)이고, 이 노트가 마지막 역이다. 거기서 샘플링은 임펄스 열과의 곱셈이고, 스펙트럼에 f<sub>s</sub>마다 복제본을 만든다고 했다. 30 kHz가 14.1 kHz로 들리는 것은 그 복제본 하나(30 − 44.1 = −14.1 kHz)가 기저대역에 떨어진 것뿐이고, 샘플링 정리 노트에서 1 kHz로 찍은 700 Hz가 300 Hz와 같아지던 계산을 숫자만 바꿔 한 것이다. f<sub>s</sub> > 2·f<sub>max</sub>는 복제본끼리 겹치지 않을 조건이고, 44.1 > 2 × 20의 여유 4.1 kHz는 거기에 필터의 전이 대역 몫을 얹은 것이다. 재생 쪽 DAC 뒤의 재구성 필터(reconstruction filter)는 샘플링 정리의 이상적 저역통과(sinc 보간)를 현실로 옮긴 것이다.

줄을 더 거슬러 올라가면, 복제본이 생기는 이유는 [푸리에 변환](/study/fourier-transform/)의 "시간에서 곱셈은 주파수에서 컨볼루션"이다. 사각파가 진폭이 1/k로 줄어드는 홀수 고조파로만 이루어진다는 사실은 [푸리에 급수](/study/fourier-series/)에서 나왔고, 위의 −14, −17, −19 dB는 그 1/5, 1/7, 1/9를 dB로 읽은 값이다. 비트당 6.02 dB와 [보드 선도](/study/bode/)의 20 dB/decade는 같은 20·log<sub>10</sub> 눈금 위의 숫자다.
